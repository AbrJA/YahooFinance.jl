Proxy Configuration

set_proxy!

Configure an HTTP proxy for all Yahoo Finance requests.

YahooFinance.set_proxy! — Function
set_proxy!(url, user=nothing, password=nothing)

Configure HTTP proxy for all Yahoo Finance requests.

Arguments

  • url::String — Proxy URL (e.g. "http://proxy.example.com:8080")
  • user — Username for authenticated proxies (optional)
  • password — Password for authenticated proxies (optional)
source

clear_proxy!

Remove proxy configuration and revert to direct connections.

YahooFinance.clear_proxy! — Function
clear_proxy!()

Remove proxy configuration, revert to direct connections.

source

Examples

# Simple proxy
set_proxy!("http://proxy.example.com:8080")

# Authenticated proxy
set_proxy!("http://proxy.example.com:8080", "username", "password")

# Remove proxy
clear_proxy!()
Security

Proxy credentials are stored in memory using Base64 encoding (HTTP Basic Auth). Ensure your proxy connection uses HTTPS if transmitting over untrusted networks.
